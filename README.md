# 🌸 She Can Foundation Website

A modern and responsive NGO landing page designed for **She Can Foundation** to promote women empowerment, education, leadership, and community impact.

This project was developed as part of a **Frontend Development Internship Task** using HTML, CSS, and JavaScript.

---

## 🚀 Features

### Core Requirements

- NGO Name
- Hero Section
- About Section
- NGO Image
- Interactive Button
- Footer

### Additional Features

- Modern Glassmorphism UI
- Fully Responsive Design
- Dark Mode Toggle
- Smooth Scroll Navigation
- Animated Statistics Counters
- Scroll Reveal Animations
- Testimonials Section
- Programs & Mission Cards
- Professional Call-To-Action Section
- Modern Gradient Background Effects

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
